
# Analysis of Air Pollution by State.
A dashboard to compare air pollution in micrograms per cubic meter in various States in the U.S in 2020.

## Dataset Used
Dataset provided from the National Institute on Minority Health and Health Disparities
[NHI (https://hdpulse.nimhd.nih.gov/data-portal/physical/table?demo=234&demo_options=air_pollution_1&physicaltopic=002&physicaltopic_options=physical_2&race=00&race_options=race_1_all&sex=0&sex_options=sexboth_1&statefips=00&statefips_options=area_states)]

## To use:
Drop down box contains all states/districts. Checking a box will filter it out of the bar graph.
